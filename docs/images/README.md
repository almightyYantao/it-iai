# Image assets

README 用到的图片素材。请按下面的清单准备并放到本目录。命名要严格一致，否则 README 里的 `<img>` 标签会显示破图。

| 文件名 | 用途 | 建议规格 |
|---|---|---|
| `logo.svg` | 顶部 logo（可选） | 240×240 SVG / PNG 透明背景 |
| `banner.png` | README 顶部横幅 | 1600×400，可放 logo + 一句 tagline |
| `screenshot-overview.png` | Web 概览页截图 | 1600×900，浏览器 chrome 可裁掉 |
| `screenshot-project.png` | 项目详情页截图（pod 状态卡 + 访问控制） | 同上 |
| `screenshot-deployment.png` | 部署详情页（实时日志） | 同上 |
| `screenshot-settings.png` | 设置页（含访问预设） | 同上 |
| `skill-push.gif` | Skill 在 Claude Code 里 push 的录屏 | 12-15 秒，<3MB，800×500 |
| `architecture.png` | 架构图（可用 [docs/技术架构.md](../技术架构.md) 里 ASCII 转 SVG/PNG） | 1600×900 |

## 推荐工具

- **截图**：macOS 自带 Cmd+Shift+4，或 [CleanShot X](https://cleanshot.com/) 加阴影更好看
- **GIF 录制**：[Kap](https://getkap.co/) (mac) 或 [LICEcap](https://www.cockos.com/licecap/) (cross-platform)
- **图标 / Logo**：[excalidraw](https://excalidraw.com/) 手绘风，或 Figma
- **架构图**：[excalidraw](https://excalidraw.com/) 导出 PNG

## 占位说明

在你补齐这些图片之前，README 里的 `<img>` 会显示破图。如果想暂时干净一些，可以把 README 里对应的 `<img>` 行注释掉（用 `<!-- -->` 包起来）。
