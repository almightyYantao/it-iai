# 爱 AI 使用手册

> 给完全没接触过代码的同学。读完大概 15 分钟，第一次跑通大概 5 分钟。

---

## 一、爱 AI 是什么

**一句话**：让你不写代码、不懂运维，也能把一个想法变成同事可以打开的网页。

**举几个例子**：

- 你跟产品聊出来一个小工具的想法，让 Claude 帮你写完，**问题**：写完只能在自己电脑上跑，没法给同事看
- 你做了个内部数据看板，**问题**：怎么挂到一个网址上，让全组人都能开会的时候点开
- 你想做个内部小机器人 / AI 小程序，**问题**：服务器 / 域名 / HTTPS / 登录都不会配

**爱 AI 把这些事全包了**：你只要有一个本地的项目（Claude 帮你写的也行），跟 Claude 说一句「部署一下」，1-3 分钟后拿到 `https://xxx.example.com`，可以直接发给同事。

自带：

- ✅ HTTPS 安全链接
- ✅ 用公司 Longbridge Account 登录（默认不是 public 的项目，外人打不开）
- ✅ 可选只允许公司内网访问
- ✅ 可以邀请同事一起改

## 二、第一次准备（5 分钟，只做一次）

### 1. 装 Claude Code

如果你电脑上还没有，问 IT 同事要安装包，或者：

- Mac：打开终端（Terminal），跑 `npm install -g @anthropic-ai/claude-code`
- 没装过 Node.js 的话，先去 nodejs.org 装一下（点 LTS 那个绿色按钮就行）

装完在终端打一个 `claude`，能进入聊天界面就 OK。

### 2. 让 IT 给你一个 Token

打开 [https://admin.example.com/](https://admin.example.com/) → 用 Longbridge Account 登录 → 左下角"会显示一串 `vbd_live_...` 的字"，那个就是你的 Token。

> 这个 Token 像门卡——能进部署系统的钥匙。**不要发到任何群里**，弄丢了找管理员重置。

### 3. 装 iai Skill（让 Claude 学会部署这个动作）

打开终端，整行复制粘贴这个命令，按回车：

```bash
rm -rf ~/iai-skill && git clone https://github.com/almightyYantao/it-iai-skill.git ~/iai-skill && bash ~/iai-skill/install.sh install
```

中途会问你：

- **Control-plane API URL** → 直接回车，或者填 `https://admin.example.com`
- **Deploy Token** → 把上面拿到的 `vbd_live_...` 粘进去（**输入时看不见，是正常的**，粘贴完按回车）

看到 `✓ authenticated` 就是成功了。

> 升级 Skill：把上面那一整条命令再粘一次就行，幂等。

## 三、第一次部署（3 分钟）

假设你跟 Claude 已经合作做了个小项目，文件夹在 `~/Desktop/my-first-app`。

1. 打开终端，进入项目文件夹：
   ```bash
   cd ~/Desktop/my-first-app
   ```
2. 启动 Claude Code：
   ```bash
   claude
   ```
3. 跟 Claude 说一句话：
   > **部署一下**

   或者：「把这个项目挂出来给同事看」、「上线一下」、「deploy 这个」——表达自由，Claude 听得懂。

4. 第一次部署会问你两个东西：
   - **Project name**（项目名）→ 回车用默认（文件夹名）就行
   - **URL slug**（网址的前缀）→ 想好记的就填，比如 `weekly-report`；回车用默认也行

5. 等 1-3 分钟，看到一个绿色的 🚀 + 网址，就好了。把网址发给同事，**他们在公司 Longbridge Account 登录后**就能打开。

## 四、日常使用场景手册

### 「我改了代码，怎么更新到线上？」

跟之前一样，在同一个文件夹里打开 Claude Code，说「重新部署一下」或「把刚才的改动上线」就行。第二次开始不会再问你项目名（系统记住了）。

### 「项目名字怎么改？」

打开项目页 → 顶部第一个面板就是「项目名称」→ 改完点保存。**slug（URL 里的那段）不会变**，所以原来的链接还能用。

> ⚠️ 第一次部署时如果通过 Claude Code 触发（非交互），Skill 会用扫描结果（通常是文件夹名）当项目名。如果你看到项目名是一串随机字符（其实是 slug），就是这种情况 —— 来这个面板改一下即可。

### 「我想要好记的网址，不要那串随机字符」

打开 [admin.example.com](https://admin.example.com/) → 点项目 → 滚到「自定义域名」面板：

**最简单的方式**：在「自定义子域」那里填一个前缀（比如 `weekly`），按回车 → 你的项目立刻多一个 `https://weekly.example.com` 的访问入口。

> 之前那个长网址还能用，不会失效——是多了一条，不是替换。
> 每个项目**默认只能加 1 个**自定义域名（含自定义子域和买的域名），需要更多请联系 IT 调整 `CP_MAX_CUSTOM_DOMAINS`。

### 「我用自己买的域名行不行」

行。同样在「自定义域名」面板，下面那块「自定义域名」填完整域名（比如 `tool.my-company.com`）。但你要**先**自己去域名供应商后台把 DNS 指过来（A 记录指到平台 IP，IT 同事会告诉你）。

> ⚠️ 它和上面的「自定义子域」**共用同一个名额**（默认 1 个）。两个二选一。

### 「我不想让所有同事都看到，只想几个人看」

两种粒度：

**a. 用 IP 白名单（按网络位置限制）**

**这一项已不再自助。** 「访问控制」面板已从项目页移除，网络层的准入策略由平台管理员统一维护，你在项目页看不到也改不了。

新建的项目默认就是**内部访问**（只有公司内网 / VPN 能打开），绝大多数情况不需要动。

需要调整的话找平台管理员，说明你要的范围。管理员改的是全局预设，改一处所有引用它的项目会自动重新挂载。

**b. 邀请协作者（按人限制）**

项目页 → 「协作者」面板 → 填同事邮箱 → 添加。

> 注：邀请协作者主要是给"能改 / 能看日志"的权限，不是限制谁能访问网址。

### 「我想让某个调用方免登录访问」

**免登录的 `public` 可见性已于 2026-07 停用**，平台现在只允许内部访问，下拉里也不再有这个选项。

如果确实有机器调用方（Slack / 飞书 webhook、外部系统回调）过不了 SSO，正确做法是只放行它要用的那条路径，而不是开放整个应用：

1. 项目页 → 「API 路径例外」面板 → 生成**项目 API Token**
2. 添加一条**路径规则**，把 `/webhook`（或它实际请求的前缀）设为用 API Token 校验
3. 让调用方在请求头带上该 Token

这样 SSO 仍然护着页面本身，只有那条前缀走 Token 校验。

### 「我想要 HTTPS / 小绿锁」

项目页 → 「HTTPS」面板 → 勾上「为本项目启用 HTTPS」→ 保存。

平台会自动给你这个项目的每个域名（默认子域 + 你加的自定义域名）申请 Let's Encrypt 证书并自动续期，大约 30 秒后浏览器就能看到小绿锁。期间 HTTP 仍可访问。

启用前请确认：

- 你的自定义域名的 DNS 已经解析到平台 IP（IT 给你的那个）
- 域名能从公网访问（外部 Let's Encrypt 校验服务器要能到 :80）

> ⚠️ 平台子域（`<slug>.<base-domain>`）通常已经有平台通配证书覆盖，不一定需要开这个开关；但加了**自定义域名**的项目想要 HTTPS，必须自己勾上。

### 「我的应用需要数据库 / Redis 缓存 / 文件存储 / SQLite 怎么办」

**不用申请，平台自动开**。你不用懂运维、不用配 DNS、不用想密码。

**A. 让 Claude 帮你识别 + 声明**

直接让 Claude 把这行加到项目根目录的 `.vibedeploy.toml`（没有就建一个）：

```toml
name = "my-app"
postgres = true     # 要 PostgreSQL
redis = true        # 要 Redis 缓存
s3 = true           # 要文件存储
sqlite = true       # 要 SQLite 持久化（自动开 Litestream 同步到 S3）
```

`true` / `false` 看你需要哪个。

**B. 部署时确认**

`deploy +push` 的时候 Claude 会问你：

```
检测到依赖:
  PostgreSQL ✓（自动开独立 DB；注入 DATABASE_URL）
  Redis ✓（自动开 ACL 用户 + 独立 key 前缀；注入 REDIS_URL / REDIS_KEY_PREFIX）
  S3 ✓（自动开独立 bucket + IAM user；注入 S3_ENDPOINT / S3_ACCESS_KEY_ID 等)
  SQLite ✓（Litestream 持续把 /data/app.db 同步到 S3；pod 重启/漂移都不丢数据）
  ⚠️  你的代码必须把 DB 路径改成读环境变量 SQLITE_PATH（默认 /data/app.db）
? 用平台自动开通这些服务？ [Y/n]:
```

回车 = 是。约 5-10 秒后平台就把对应的资源开好了。

**C. 应用代码里直接读环境变量**

部署成功后 pod 里这些环境变量已经存在，应用代码直接读就行：

| 服务 | 环境变量 | 用法举例（Python） |
|---|---|---|
| PostgreSQL | `DATABASE_URL` | `psycopg.connect(os.environ["DATABASE_URL"])` |
| Redis | `REDIS_URL` + `REDIS_KEY_PREFIX` | `r = redis.from_url(os.environ["REDIS_URL"]); r.set(os.environ["REDIS_KEY_PREFIX"]+"hello", "world")` |
| S3 | `S3_ENDPOINT` / `S3_ACCESS_KEY_ID` / `S3_SECRET_ACCESS_KEY` / `S3_BUCKET` | `boto3.client("s3", endpoint_url=os.environ["S3_ENDPOINT"], ...)` |
| SQLite | `SQLITE_PATH`（默认 `/data/app.db`） | `sqlite3.connect(os.environ.get("SQLITE_PATH", "./app.db"))` |

**SQLite 的特殊说明：**

代码里**必须**把 DB 文件路径改成读 `SQLITE_PATH`，否则会写到容器内某个临时目录、pod 重启就丢。
跟 Claude 说一句「**把 SQLite 路径改成读 SQLITE_PATH 环境变量**」就行。

平台做的事：pod 启动时 init container 从你的 S3 bucket 拉最新快照恢复到 `/data/app.db`；sidecar 持续把 WAL 增量同步回去。你只管像本地 SQLite 一样写。

**D. 隔离保证**

- 你的 PG 数据库别人**连不上**（独立账号 + GRANT 限制）
- 你的 Redis key 别人**看不到**（ACL 限制，跨前缀写入直接 NOPERM 报错——所以 Redis 必须**用 `REDIS_KEY_PREFIX` 给 key 加前缀**，否则会写失败）
- 你的 S3 bucket 别人**列不出**（IAM policy 锁死）
- 你的 SQLite 数据库就在你自家的 S3 bucket 里（复用上面这条隔离）

**E. 想自己用外部数据库（RDS 之类）**

部署时按 `n` 跳过自动开通，然后在 Web 后台「环境变量」面板手工填 `DATABASE_URL` 等。

### 「部署完了，但页面打不开 / 报错」

打开项目页 → 看上面的 pod 状态卡片。

- **Phase: Running · Ready** → 应用本身是好的，**检查你访问的网址有没有写对**
- **Phase: Pending** → 还在启动，等 1 分钟
- **Phase: CrashLoopBackOff** 之类的红字 → 应用代码有问题，让 Claude 帮你看日志：「拉一下最近的运行日志」

### 「我想看部署过程的日志」

部署的时候 Claude 已经实时打出来了。事后想再看，去：项目页 → 「最近的部署」点任一条 → 看实时日志。

### 「不要这个项目了，怎么删」

项目页拉到最下面，红色「危险区域」→ 输入项目 slug 确认 → 「永久删除该项目」。

⚠️ 删了就没了，网址、镜像、配置一起清掉。审计记录保留。

## 六、常见问题 FAQ

**Q：我说「部署」Claude 没反应？**
A：可能是 Skill 没装好或者 Claude 没重启。先关掉 Claude Code 重新打开。还不行就重新跑一次安装命令。

**Q：终端里输 Token 的时候没显示字？**
A：正常。密码类输入都不会回显，粘进去按回车就行。

**Q：第一次推送很慢？**
A：第一次构建会下载基础工具（~2-4 分钟），第二次开始同一个项目会快很多（一般 30 秒-1 分钟）。

**Q：我的项目里有密码 / API key 怎么办，会上传吗？**
A：会。**不要**把密码直接写在代码里。让 Claude 帮你把敏感信息提取成环境变量，部署时通过项目设置注入。如果你不确定，部署前问 Claude 「这个项目里有没有应该当作密码处理的东西」。

**Q：自定义子域名能跟别人重复吗？**
A：不能。后台会立即提示「该域名已被其他项目占用」。

**Q：能给项目挂自己买的域名吗？**
A：可以。但需要先去域名服务商那里改 DNS 指过来。不会改就找 IT。

**Q：忘记了部署到哪里、网址是什么？**
A：去 admin 后台 → 项目 → 找到这个项目，URL 在右边那一列。

**Q：我的项目突然停了？**
A：先看项目页 pod 状态。如果状态是 Stopped / Error，可能是程序自己崩了，让 Claude 看运行日志找原因。如果状态显示 Running 但访问不到，先清一下浏览器 cookie / 试无痕窗口。

**Q：我能改别人的项目吗？**
A：除非你是项目所有者、被对方加为协作者、或者你是管理员，否则不能。

## 七、跟 Claude 对话的常用句式

你不用记命令——用最自然的话说就行。下面是 Claude 听得懂的几种说法，挑顺口的用：

**部署 / 上线**
- 「部署一下」「上线」「把这个推上去」「deploy」

**更新**
- 「重新部署」「再上一次」「更新到线上」「redeploy」

**看状态**
- 「线上跑得怎么样」「现在状态如何」「status」

**看日志**
- 「拉一下最近的日志」「跟一下运行日志」「logs -f」

**列出项目**
- 「我都有哪些项目」「list」

**邀请协作者 / 改域名**
- 这些 Claude 也能帮，但**更建议直接去 admin 后台点**，所见即所得，不容易搞错
